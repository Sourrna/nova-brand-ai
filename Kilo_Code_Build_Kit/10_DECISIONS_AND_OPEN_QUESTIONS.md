# Decisions and Open Questions

## Established
1. Sourena owns the public brand; NOVA is internal.
2. Build useful MVP before expanding features.
3. Avoid unnecessary Lovable messages/credits; Kilo Code is the proposed workflow.
4. Never fabricate credentials, skills, clients, revenue, users, or results.
5. Publication requires explicit, item-specific approval.
6. ChatGPT memory is not assumed to sync with other tools.
7. LinkedIn posting/profile editing is not assumed connected.
8. Build/test/deploy claims require evidence.
9. Exclude unrelated sensitive personal information from professional exports.

## Discover from code, not guess
- Framework/version, storage/backend, authentication, routes and current data model.
- Actual build/test/typecheck/lint scripts.
- Current branch, uncommitted changes and deployment state.
- Which features already work and which integrations are genuinely connected.

## Decisions to ask only when they affect implementation
- Local-first only or cross-device sync?
- Required deployment target?
- Default language: Persian/RTL, English, or both?
- Which project claims are explicitly approved for public use?
- Is an AI provider allowed and what are the cost/privacy limits?

Do not block the initial audit by asking all questions upfront. Inspect the actual state first.
