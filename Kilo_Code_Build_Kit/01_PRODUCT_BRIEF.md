# Product Brief — Sourena Brand OS

## تعریف
Sourena Brand OS یک فضای کاری خصوصی برای طراحی و اجرای برند حرفه‌ای سورنا است. **Sourena صاحب برند عمومی است؛ NOVA مغز راهبردی/عملیاتی داخلی است، نه نام برند عمومی.**

## چرخهٔ ارزش
`هدف → انتخاب پروژه → برنامهٔ اجرا → خروجی/شاهد → مستندسازی → پیش‌نویس محتوا → بازبینی انسانی → تأیید صریح`

## مسئله
اطلاعات، پروژه‌ها، شواهد، مهارت‌ها و پیش‌نویس‌های برند در ابزارهای مختلف پراکنده‌اند. محصول باید حافظه‌ای قابل‌انتقال و قابل‌ویرایش بسازد و به‌جای گسترش بی‌پایان امکانات، کار را به خروجی قابل‌اثبات تبدیل کند.

## نقش‌ها
- **Owner: Sourena** — مالک داده و تصمیم‌گیرندهٔ نهایی.
- **NOVA/AI** — تحلیل، برنامه‌ریزی، مستندسازی و پیش‌نویس؛ نه مالک برند.
- MVP تک‌کاربره است. ثبت‌نام عمومی و چندمستاجری در محدودهٔ اولیه نیستند مگر اینکه معماری فعلی الزام کند.

## اهداف MVP
1. داشبورد متکی بر دادهٔ واقعی.
2. مدیریت پروژه‌ها و next action.
3. فهرست مهارت‌ها و شواهد قابل‌بررسی.
4. حافظه با منبع، سطح اطمینان و حریم خصوصی.
5. ساخت و نگهداری پیش‌نویس محتوا، بدون انتشار خودکار.
6. Import/Export به Markdown و JSON نسخه‌دار.
7. قفل حریم خصوصی و تأیید صریح انتشار.
8. هزینهٔ پایین و عدم وابستگی اجباری به API پولی.

## خارج از MVP
انتشار خودکار LinkedIn، اتصال ادعایی بدون API/OAuth واقعی، عامل خودمختار با دسترسی نامحدود، پرداخت، تیم چندکاربره، تضمین درآمد/رشد، و AI provider اجباری.

## معیار موفقیت
بتوان پروژه ساخت و ویرایش کرد، شاهد به آن وصل کرد، پیش‌نویس ذخیره کرد، داده را export/import کرد، پس از reload داده‌ها را حفظ کرد و ثابت کرد که چیزی بدون تأیید صریح منتشر نمی‌شود.

**اصل:** Evidence before claims. Approval before publication. Execution before feature expansion.
