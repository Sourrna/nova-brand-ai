# Knowledge States

| State | Meaning | Usable publicly as fact? |
|---|---|---|
| VERIFIED | Backed by evidence (link, repo, commit, document) or explicit owner confirmation | Yes |
| USER_PROVIDED | Stated by the owner, no evidence attached yet | Yes, phrased as the owner's own statement |
| INFERRED | Deduced or generated by Nova/AI | No |
| NEEDS_CONFIRMATION | Incomplete or uncertain | No |

Rule: never present INFERRED or generated content as verified fact.
