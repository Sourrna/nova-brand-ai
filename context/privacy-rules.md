# Privacy Rules

| Visibility | Who sees it | In public content? | In Nova export? |
|---|---|---|---|
| PUBLIC | Anyone | Yes | Yes |
| INTERNAL_STRATEGY | Owner + Nova | No | Yes |
| PRIVATE | Owner (+ Nova on request) | No | Only "full" export |
| SENSITIVE | Owner only | Never | Never stored here — keep outside the repo |

- Repository stays **private**.
- No credentials, tokens or secrets in this repository, ever. They belong in Lovable project secrets.
