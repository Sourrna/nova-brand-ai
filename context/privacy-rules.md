# Privacy Rules

| Visibility | Public export/draft candidate? | Nova export? |
|---|---|---|
| PUBLIC | Only VERIFIED / USER_PROVIDED, still subject to explicit approval before public use | Yes |
| INTERNAL_STRATEGY | No | Yes |
| PRIVATE | No | Only explicitly selected full export |
| SENSITIVE | Never | Never |

PUBLIC is eligibility for review, not permission to publish. Nothing becomes public without Sourena's explicit approval, even routine branding. File edits, GitHub analysis/repository creation, profile edits, destructive actions, permissions and disconnections also require approval. This profile-update request authorizes only its scoped local changes.

Private project details, BetaBazar revenue/team narrative, client identity and research details never enter public exports or draft source options by default. Skills are internal owner self-assessments. Content exports must respect the privacy of their source records. Progress logging is opt-in until confirmed.

Repository must remain private; the bundled app is an owner control layer, not a public portfolio. Do not publish it with private context bundled. No credentials, tokens or secrets in this repository.
